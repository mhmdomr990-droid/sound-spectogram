# مطابقة ألوان اللوق مع الخطي — الجذر (الهوية + الذروة)

## المشكلة
- نفس البيانات (آخر باكت، نفس الكسب) → الخط الرفيع العلوي أصفر في الخطي، **وردي/باهت** في اللوق (اللقطتان 11:48:00 / 11:48:15).
- الهندسة متطابقة تماماً → `topLinear = true` (تركيز 200 / أقصى 250 → ضغط مستحيل) → المحور خطي هندسياً، لكن `warpSpectrogramIntensity` تُنفَّذ رغم ذلك.
- `mapRow` يعطي `t = 0.5` لكل صف (عيّنة منتصف البكسل: `h − y − 0.5`) → كل بايت = `avg(صفَّين متجاورين)` → الخط الرفيع (صف واحد ساطع) ينزل نصف شدته في LUT → وردي.
- الخطي: nearest نسخ بدون خلط → شدة كاملة → أصفر.
- التعديل السابق (`mix(bilinear, max, 0.5)`) فشل لأنه استعيد نصف النقص فقط + الهوية تخلط أصلاً + الضغط يبقى bilinear مركزاً.

## الإصلاح — `flutter_app/lib/utils/log_axis.dart` — `warpSpectrogramIntensity`

1. **مسار الهوية**: إذا `axis.topLinear` (أي: min → 0، وshare = lowSpan/range → المحور خطية تماماً) → **إرجاع `src` كما هي** (نسخ صفوف، بلا خلط) → تطابق خطي 100% + تسريع (تخطي warp).
   - الشرط: `if (axis.topLinear) { /* copy rows src→out, dstW مطابق */ return; }` (أو في `_upscaleAndWarp` قبل النداء).
2. **التمدد (footprint ≤ 1)**: `value = max(row[ya], row[yb])` بدل `mix(bilinear, max, k)` → الخطوط الرفيعة بنفس شدتها في الخطي؛ الخلفية الداكنة `max(داكن, داكن)` لا تتغير.
3. **الضغط (footprint > 1)**: مركز العيّنة يصبح `max(صفَّي العيّنة)` بدل bilinear؛ `pool` + `wBlend` كما هي.
4. تعليق التوثيق: يصف الذروة-بديل-المتوسط + مسار الهوية.
5. `test/warp_display_test.dart`: قد يثبّت قيم bilinear قديمة → تحديث التوقعات.
